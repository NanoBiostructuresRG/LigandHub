About

LigandHub (v0.1.0) is a web-based platform for ligand preparation in molecular docking workflows. It accepts molecular structures in common input formats, including SDF, PDB, MOL2, and SMILES, and generates PDBQT files for downstream docking. It also supports recovery of docked ligand coordinates from PDBQT or DLG result files into SDF format for downstream analysis and visualization.

Data handling: Uploaded files, including SMILES-containing text files, are stored only temporarily during request processing and are not intentionally retained by the application afterward.

Processing: Ligand preparation is performed on the backend using Meeko (0.7.1) and RDKit (2025.9.2).
