About

LigandHub is a free browser-based interface designed to support ligand preparation for molecular docking studies. The platform accepts molecular structures in common input formats, including SDF, PDB, MOL2, and SMILES, and generates PDBQT files. Depending on the input structure, the preparation process may include hydrogen addition and 3D coordinate generation before export.

Data handling: Uploaded files and SMILES inputs are used temporarily during the request and are not intentionally retained by the application afterward.

Processing: Ligand preparation is carried out on a backend server using Meeko (LGPLv2.1) and RDKit (2025.9.2).
